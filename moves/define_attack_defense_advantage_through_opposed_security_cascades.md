before: >-
  knowledge: holds a variable as announced but undefined, aware only that it
  is one of several factors said to shape a larger phenomenon. question:
  holds an unanswered question about how the announced variable operates.
  expectation: expects the next unit to define an abstract variable before
  using it. orientation: may see the variable's two states as expressing
  opposed motives rather than alternative means to one end. trust: has been
  told a framework exists but has not seen it demonstrated.
after: >-
  knowledge: distinguishes the variable's two states operationally and can
  link each to a distinct chain of downstream consequences. question: holds
  a narrower question about how the variable maps onto specific cases.
  expectation: expects the larger argument to explain particular cases by
  classifying them into one of the two states. orientation: sees both states
  as alternative means toward the same underlying goal, with context
  determining which means is rational. trust: has watched a familiar,
  controlled contrast carried systematically into the target domain, though
  its broader empirical claims remain asserted rather than established.
technique: >-
  Define a binary variable in parallel terms, then simplify it through two
  cases that hold an underlying motive constant while varying only the
  available means, so the causal distinction rests on the means rather than
  on an assumed difference between the cases. Transfer the resulting
  distinction to the target domain and trace each state through the same
  categories of outcome, producing two mirrored causal chains that can be
  compared directly.
breaks: >-
  remove: dropping the statement that the two illustrative cases share the
  same underlying motive lets the contrast be read as a difference between
  the cases themselves rather than between their available means, defeating
  the isolation the variable requires. reorder: placing the target-domain
  consequences before the controlled small-scale contrast strips the
  abstract causal claims of the intuitive support that makes the means-based
  distinction legible. extend: folding a second, independent variable into
  the same unit compresses a clean single-axis elaboration into a survey and
  weakens each mirrored consequence chain.
