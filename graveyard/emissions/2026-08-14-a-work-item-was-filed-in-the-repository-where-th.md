## Trigger — what happened

A work item was filed in the repository where the problem was noticed. Its remedy asked for a change to one named file, and that file belongs to a different repository — nothing in the intake had asked whether the file was here. The sitting found out by looking for it.

## The learning

A report names the place the trouble showed up; it does not name the place the repair goes, and the two are routinely different. So before deciding what kind of work an item is, check that the thing it asks you to change is actually in front of you — a single existence check, done first, costs nothing and settles the question. Done later it is expensive, because by then the item has been planned as local work. When the surface turns out to belong elsewhere, hand the whole item over and leave a pointer behind rather than closing it: the receiving side gets a record that can be acted on, and the original keeps a trail back. Splitting is only honest when the sending side really does still owe something of its own.
