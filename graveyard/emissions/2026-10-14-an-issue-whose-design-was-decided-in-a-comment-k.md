## Trigger — what happened

Reviewing the five open paragraph-Move Issues on 2026-10-14: #1368's body still described the Writer receiving a Move after the owner had reversed that in a comment the same morning; #1365 named a flag the tool had refused by name since #1369 and two blockers that had landed; #1330 carried an Acceptance reading 'written at admission'. Three Issues were edited in one sitting without any new decision.

## The learning

When a decision is recorded as a comment on an Issue, the body it supersedes stays the carrier the admitting run and the implementer read. The next sitting that touches the Issue has to fold the comment into the body, re-point blockers whose Issues have landed, and write the Acceptance, or the implementer inherits the architectural choice. A review pass over every open Issue in a design area, done before the next run picks one up, is cheaper than the stop-and-revise the stale body causes mid-run.
