## Trigger — what happened

/ship-cycle 1186, 2026-09-25: the worker finished the issue, but its seam test is required to fail whenever the Gateway is absent, which makes CI red on every run. The owner chose re-admission as needs-decision, and admit-issue plan offered no way to reach it, because its only check is computed pass from an empty served denominator and takes no answer.

## The learning

The implement lane's rule for a mid-implementation design question says to stop and re-admit so the issue lands on needs-decision. That exit only exists if admission has a check the session can answer. When every check is computed by the engine, re-admission can only re-stamp the same route, record-pass has no outcome to record, and the run cannot close through its typed path. Separately, an acceptance criterion that tells a registered check to fail when a machine-local input is missing contradicts a CI that never has that input. That contradiction should be caught when the issue is filed, not found at implementation.
