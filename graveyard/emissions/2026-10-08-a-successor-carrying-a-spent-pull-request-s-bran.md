## Trigger — what happened

kogaki#1309 carried all 23 files of spent PR #1308. Admission refused that footprint at the tool-call ceiling, then at the read window, then as uncovered, before a narrowed cell admitted.

## The learning

When a successor Issue carries a whole branch forward, the carried changes are already committed. The worker opens none of those files, so they do not belong in the plan's footprint. The footprint names only the files the worker edits, with a region on each edited span and one small registered check that covers them. Admission sizes the cell at the Issue's own branch when one exists, and the worker reuses a surviving branch of that name, so having that branch in place before dispatch is what makes the carry real.
