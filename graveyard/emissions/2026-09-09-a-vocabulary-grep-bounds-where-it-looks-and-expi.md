## Trigger — what happened

A vocabulary retirement was accepted as a grep over three named files. Satisfying it moved one sentence that a second file read back VERBATIM as a block boundary, so the two files disagreed about the Packet's layout while every fixture case stayed green — the runtime check caught it, not the grep. Separately, the grep's own criterion had no standing carrier: run once in the sitting it says the tree was clean that day and nothing about the next.

## The learning

A vocabulary retirement expressed as a grep over named files is one-sided in two ways at once, and each needs its own repair in the same act. First, the grep bounds WHERE it looks, so a term that is load-bearing across that boundary — a sentence one file matches verbatim inside another — is edited on one side and left on the other, and the break is invisible to both the grep and to any fixture that writes its own copy of the coupled artifact: the tell is a check that reads the REAL carrier rather than a fixture. Second, the grep measures only what must not remain, so it is cheapest to satisfy by deleting behaviour and it expires the moment the sitting ends; it owes a standing carrier holding the term list as data, and that carrier owes a header naming the half it does not hold — the behaviours that must survive, each with the case that fails if it stops holding.
