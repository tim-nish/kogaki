## Trigger — what happened

kogaki#1529 dropped the kind of an introduced term (coined or established) from the Brief. The Proof Sheet's --terms file, added at kogaki#1498, existed only to pin that kind for a run, so it had nothing left to pin.

## The learning

When a field leaves a record, search for the tools whose whole job was to set, fix or check that field, not only the readers of the record. Here a Proof Sheet flag kept accepting a file that pinned a value no longer written anywhere; left in place it would have run silently and changed nothing. The fix was to refuse the flag by name with one sentence saying why and that nothing was started, in both entry points that accepted it, and to keep only the read of old run records that carry it.
