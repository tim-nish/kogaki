## Trigger — what happened

kogaki#1569 required an Obligation's owed span to be an unbroken run of units. The Issue named the two validators and their checks, but the full suite also failed in the Proof Sheet, whose four-Leg case built a row owed by Legs b and d.

## The learning

When a rule about the shape of a record gets stricter, every place that builds that record can now produce one the rule refuses, and the Issue's list of files usually names only where the rule is checked. Here the Proof Sheet builds the owed span from whichever Legs introduce the deferred terms, so a library where those Legs are not next to each other now yields a Brief that is refused, not one that passes. Before sizing such a change, search for code that builds the record as well as code that checks it, and run the whole suite before the footprint is settled.
