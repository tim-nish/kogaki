## Trigger — what happened

Composing terrain's J2 subdivision record for a 218-placement tag: src/workflow.json's J2_subdivision refusal text names the closed coherence set as 'tight | related | forced', while src/terrain.mjs has held 'tight | related | loose | other' since kogaki#738. Composing to the table's stated set would have been refused by the runtime, and the table is the artifact the skill sends a reader to for what the state accepts.

## The learning

When one file is declared the control plane for a machine's behaviour, the vocabulary quoted inside its prose fields is a conformance copy of what the code enforces, and it goes stale in exactly the way a duplicated constant does — silently, and only for readers. The table's structural fields were correct throughout; the drift was entirely in the sentence describing a refusal. A carrier that a reader is told to read INSTEAD of the code owes a check over the vocabulary it quotes, or it must quote nothing and point at the enforcing site instead. The general form: a document whose authority is 'read this rather than the implementation' cannot restate the implementation's closed sets in prose without a mechanism that fails when they diverge.
