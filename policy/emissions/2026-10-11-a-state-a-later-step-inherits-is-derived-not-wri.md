## Trigger — what happened

kogaki#1325: each Leg of an article plan wrote its own 'reader state before', and a model judge checked it was a 'consistent specialization' of the state it followed. In one run the judge accepted a before-state that gave the reader knowledge no text had stated, and the draft's opening skipped the rule it relied on.

## The learning

When a step's starting state is, by meaning, the previous step's ending state, derive it and refuse any written copy; do not let the author restate it and then ask a judge whether the restatement is close enough. A restated copy gives the author a place to add content, and a vague 'is this a specialization' test lets the addition through. With the state derived, the judgment that remains runs the other way: does the next step need anything the inherited state does not hold. A comparison between two lines that are now the same line (here, path review's question chain) is retired with its checks, not re-pointed.
