## Trigger — what happened

In a round-trip review, one comparison item pairs the concessions a blind reader found in the prose against the ones the plan declared. The file put in front of the judge rendered that recovered list as the string that appears when a program prints structured records without converting them — a repeated placeholder carrying no text. Every judge who met it answered that it could not decide, correctly, because there was nothing readable to compare. The item is one whose failure would send the passage back for rewriting, and it went unanswered on four passages, through both review passes, and reached the owner's record as an undecided line rather than as a defect in the tool.

## The learning

A comparison can be starved by its own presentation layer, and the failure is invisible to everything that checks the comparison is complete. The pairing was assembled correctly and the judge was asked correctly; only the step that turned one side into readable text was wrong. Because the honest answer to an unreadable pair is 'cannot decide', and because that is a legitimate answer the process is built to accept and carry forward, the defect arrives dressed as a normal outcome — no count is short, no step refuses, nothing is missing. The tell is repetition: one undecided pair is a hard case, the SAME item undecided on every passage that has one is the rendering. Check what the judge was actually shown, not that it was shown something.
