## Trigger — what happened

A Terrain gate declared exactly one admissible act — sending a payload file — and denied every tool inside the interval, the Read that would fetch that file included. The start message named the file and printed none of its bytes. Both refusals were correct on their own terms and jointly unrenderable: the session could not obtain what the only admissible act required, blocked eight times at Stop, and the run died with the gate never rendered. The recovery was a person moving a pointer by hand from outside the session.

## The learning

Where a mechanism admits exactly one act, whatever that act CONSUMES must arrive on a channel that already exists before the interval opens — not as an address the actor is expected to resolve, because resolving an address is itself an act and the interval denies acts. A path is an instruction to fetch, and the fetch is inside the closure. The repair is delivery, never an exemption: admitting the one read that would work puts a second admissible act inside an interval whose entire property is that exactly one is, and the exemption then has to be argued case by case forever. Deliver the bytes on the channel that predates the gate — here the stdout the skill expansion already hands to the session — and leave the written artifact as the reference the equality check still compares against, so nothing about the enforcement widens. The symptom to watch for is a deny message that tells the actor to do something the same deny makes impossible; that is not a fail-closed gate, it is a wedge, and a wedge relocates the choice rather than preventing anything.
