## Trigger — what happened

An audit enumerating consultation-dependent capabilities scored any file containing the word receipt as receipt-validating, which swept in every file merely carrying a consulted: line as its own provenance. Seven of twenty-four candidates dropped out when the property was re-bound to three separable tests: does it invoke the transport, does it parse the grammar, does it read the map as data.

## The learning

An audit that scores membership by the presence of a term conflates CARRYING a mark with DEPENDING on what the mark records, and the two are opposite relations to the same vocabulary: a file that carries a provenance line is downstream of the thing, while a file that parses that line is upstream of it. The inflation is invisible from inside the result, because every false member genuinely contains the term and the enumeration visibly works on what it matches. The remedy is to state the property as a relation the artifact stands in, then bind one test per relation, so a member qualifies on a named arm rather than on a word.
