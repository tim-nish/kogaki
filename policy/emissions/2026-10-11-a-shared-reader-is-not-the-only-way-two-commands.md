## Trigger — what happened

On kogaki#1327 the implement worker made the Draft command import the Brief command's Thesis reader so the two could not disagree, and the ownership check refused the import: a command module imports no other command's. The cell's footprint licence covered only the Draft side, so no shared file could be added without re-admission.

## The learning

When two commands must agree about a format, a shared function is one way and a shared grammar is another. Where the boundary rule forbids the import and the cell cannot widen its footprint, each side reads the format with its own small reader and both answer to the written grammar. Choose the shared file only when the plan already licenses it.
