## Trigger — what happened

A new feature added a reader for a data block, and a comment elsewhere in the same file stated flatly that no reader for that block existed. The comment's actual argument — about which item on a different axis carries a property — remained true; only its opening factual claim had been falsified.

## The learning

When a change falsifies a sentence in a nearby comment or document, check whether it falsifies the sentence's ARGUMENT or only the flat fact the argument opened with. These come apart often: a note says 'nothing reads X, so we use Y here' and the new work adds a reader for X on a different axis, leaving the reason for using Y untouched. Deleting the whole passage loses a live argument; leaving it loses the reader's trust in every other claim around it. Narrow the sentence to what it was arguing, and say in the same edit that it was narrowed and why. The failure to avoid is quietly rewriting it so a later reader cannot tell the clause ever said something stronger.
