## Trigger — what happened

The one-Leg Proof Sheet run of 2026-10-26 (leg-run-2026-10-25T15-25-44-256Z) fired the counts trigger on the paragraph that counts two factors, yet wrote one generic obligation item, and the Planner's ledger recorded the paragraph that names the factors as discharging the promise.

## The learning

When a judgment is made source-free on purpose, from an abstract description alone, every fact the judgment must reproduce has to be carried in that description. The obligation call reads only each Segment's operation and relation, and the Extractor wrote the count as 'a fixed small number of parts', so the number two never reached the call and one item per counted part was impossible by construction. The same run's Leg Move, whose operation said 'pair', produced first and second items. The rule for a counting operation is that its wording carries the count. A second gap follows: a ledger row discharged by the unit that merely names the counted items reads naming as keeping the promise; discharge must be by explanation.
