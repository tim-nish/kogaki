## Trigger — what happened

A closing emitter defines a legitimate exit grade whose condition is that a row of its table names an open pull request, and the rows are supplied by the caller — but its command line offers no flag to supply one. The grade is therefore unreachable from that surface, and the run had to close as a failure with a typed cause instead.

## The learning

When a tool defines an outcome whose precondition is content the caller must provide, check that the caller has a way to provide it. A grade, status or verdict that no invocation can satisfy is worse than one that does not exist: it reads in the contract as an available outcome, so every run that should have taken it reports something else, and the record then under-counts that outcome forever while looking complete. The tell is a refusal that names a condition in terms of data rather than of state — 'no row carries one' rather than 'the pull request is not open'. When you meet it, report the unreachable grade alongside the one you were forced into, so the count is legible as an artifact of the surface rather than as a fact about the runs.
