# Kogaki (小書)

Writes development articles from the owner's ratified knowledge substrate
(the Gukan pattern: Grains, Threads, Glossary), served read-only through the
tsurezure-gateway seam. Successor of `writing-assistant` (archived
2026-08-04; its address is never recycled).

The boundary that defines the project: **repositories are invisible to
Kogaki.** Article material is quoted from served plain-register renderings
at pins; Kogaki guarantees the citations, the substrate guarantees the
facts. See `specs/SPEC.md`.

Without a configured policy source the tool still runs, degraded and saying
so — the substrate is an enhancer, never a hard dependency.
