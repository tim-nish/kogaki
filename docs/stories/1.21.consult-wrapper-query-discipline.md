## Acceptance criteria

1. **Given** a claim to check, **when** the entry point is invoked with it,
   **then** it runs the lookup and emits the receipt through story 1.20's
   emitter — one path, no second receipt composer.

2. **Given** a **verdict-shaped** input (a question asking whether something is
   acceptable, correct, or problematic rather than stating a claim), **when** it
   is submitted, **then** the entry point returns the one fixed correction at the
   point of use — *the seam serves positions, not verdicts; state the claim the
   decision turns on* — rather than forwarding the question. The correction is
   an affordance, not a denial: the corrected claim is re-submittable in the same
   act.

3. **DEFERRED — do not implement before the slot is filled.** **Given** a
   non-discriminating first return, **when** the entry point continues, **then**
   exactly one re-framing along a different axis is performed or prompted for,
   and the `outcome` token is assigned per whatever kogaki#66's decision gate
   records for `deferred-slot: consult-outcome-token-assignment`. Until that
   record exists, the entry point takes the token from its caller and fails
   rather than guessing (story 1.20 AC 4).

4. **Given** any consult through this entry point, **when** it completes,
   **then** every framing actually run appears as its own `query:` line — one
   axis, a fixed bound, never a search loop.

5. **Given** the entry point is unavailable or the gateway is unreachable,
   **when** a session needs to consult, **then** the degraded path is the
   existing one and is stated rather than silent: the direct MCP tools plus a
   hand-composed receipt carrying story 1.20 AC 5's exception marker. The
   discipline degrades to prose; it does not degrade to nothing.
