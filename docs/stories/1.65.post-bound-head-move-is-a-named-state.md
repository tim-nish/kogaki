**As** the review lane,
**I want** a head that moves past a spent round bound to resolve to its own
named state rather than to a generic `park`,
**so that** the supersession lane is the routed actor instead of the owner
being asked to arbitrate a state the lane itself manufactured.

## Context, grounded

`tools/review-sweep.sh:3760-3761` returns `park` whenever
`rounds_done >= MAX_ROUNDS` and the current head carries no **counted** report.
That is the same token as *the bound is spent and nobody pushed anything*, so
the fix commit — the act clause 3 forbids — leaves no distinguishable trace in
the state machine. `supersede` at `:3725-3726` is not reachable for this shape:
it requires a counted report **at the current head** carrying open blocking
findings, and a head that has just moved has none.

**Counted and performed are different sets here, and the difference is this
story's discriminator** (see AC2b). `:3694` gates on `counted(s)`, while
`rounds_used()` counts **performed** segments through `rally_cycles()` at
`:2027-2028`; §4 clause 6 makes a fragment performed and not counted. So "the
head carries no counted report" is true of a fragment too, and only "no
performed segment at all" isolates the head that actually moved past the bound.

`specs/SPEC.md` row 11 records this transition, typed `none: OWED AND UNBUILT`
with this story as its carrier. **This story's landing change re-types row 11
to `act`** — clause 9's re-typing trigger, discharged in the same change, per
row 4's precedent.

## Acceptance criteria

**AC1 — the state exists and is distinguishable.**
GIVEN a PR whose rounds are spent (`rounds_used >= MAX_ROUNDS`)
AND whose current head carries **no performed segment at all**
AND at least one **earlier** head carried a counted report
WHEN `decide()` runs
THEN it returns a state distinct from `park`, naming the post-bound head move.

**AC2 — the plain park is unchanged.**
GIVEN a PR whose rounds are spent and whose head carries no report
AND **no** earlier head carried a counted report — nothing was ever reviewed
WHEN `decide()` runs
THEN it still returns `park`.
*(This is what keeps AC1 from swallowing the existing state: the discriminator
is that a head MOVED, not merely that the bound is spent.)*

**AC2b — a FRAGMENT at the current head is not a post-bound head move.**
GIVEN round 1 reported whole at head A
AND the author's in-bound fix moved the head to B
AND the round-2 report at head B is a **fragment** (§4 clause 6 — its declared
`report-complete: <N>` does not match its finding lines)
WHEN `decide()` runs
THEN it does **not** return AC1's state: the head moved *inside* the bound, and
the condition is a fragmented report whose remedy is re-posting it whole.

*(Why this is its own criterion, from PR #452 round 1 finding 4.* AC1's first
draft read *"current head carries no report"*, and that is satisfied by the
fragment case: `decide()` enters the `park` arm on `not any(counted(s) for s in
current)` at `tools/review-sweep.sh:3694`, while `rounds_used()` counts
**performed** segments through `rally_cycles()` at `:2027-2028` — and clause 6's
whole split is that a fragment is performed and not counted. So rounds-used
reaches 2, the current head carries no *counted* report, an earlier head carried
one, and the draft discriminator fired on a head that never left the bound. AC3
would then have routed it to supersession and AC4 spawned nothing, telling the
author to open a successor for a report the reviewer merely split — while
clause 6 already requires the sweep to name the fragment case by name. The
discriminator is therefore **performed**, not **counted**.)*

**AC3 — the routed actor is supersession, not arbitration.**
GIVEN the state from AC1
WHEN the driver renders it
THEN it names the supersession lane and the findings the successor owes, in the
shape `supersede` already uses, and does NOT request owner arbitration.

**AC4 — it spawns nothing.**
GIVEN the state from AC1
WHEN the driver runs
THEN no review round and no fix round is spawned — clause 3's bound is spent
and this state does not re-open it. Asserted through `drives_fix()` rather than
by reading the branch, as `unadjudicated` already is.

**AC5 — the mutations that remove the discrimination fail a fixture.**
GIVEN the new state's fixture cases
WHEN the discriminator is mutated so the state collapses back to `park`
THEN a fixture fails, naming the collapse.
AND WHEN the discriminator is mutated from **performed** to **counted** — the
draft's own defect, AC2b — THEN a fixture fails on the fragment case.
*(Written as a criterion because the whole defect is a state that reads as
another state; a fixture asserting only the happy path cannot see it.)*

**AC6 — row 11 is re-typed in this same change.**
GIVEN this story's change lands
THEN `specs/SPEC.md` row 11 reads `act` and names the shipped observer, and the
`OWED AND UNBUILT` text is gone — not left beside it.
