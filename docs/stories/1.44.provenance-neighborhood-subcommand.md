## Story

As the owner surveying Strands for an article, I want a candidate Strand set's
**provenance neighborhood** enumerated and offered beside it, so that a
contemporaneous Grain under an unrelated tag is reachable rather than silently
excluded by the co-tag bound.

## Grounding

- The subcommand is a **sibling of `cotags`, never a change to it** — `cotags`
  is `terrain/terrain.mjs:574` (`function cmdCotags`), and the dispatch table
  it joins is `terrain/terrain.mjs:2128-2138`.
- **No Thesis input exists in the tool today.** `terrain/terrain.mjs` mentions
  a Thesis only in two comments (`:702`, `:1567`) and carries no such argument,
  so this is new plumbing rather than rewiring. Read at `6e1c873`.
- The `members` join shape is `{"members": {"journey": [...], "lesson": [...]}}`
  (`gloss/ELEMENTS.jsonl:745`), family-keyed, per §13.3.

## Acceptance criteria

**AC1 — two required inputs (§13.2).** Given a candidate Strand set and a
tentative Thesis, when the subcommand runs, then it accepts both; and when the
Thesis is absent, then it refuses rather than falling back to Strand-set-only
similarity, which §13.2 declines.

**AC2 — the three substrates enumerate (§13.3).** Given a candidate set, when
the neighborhood is computed, then members are reached via `source_batch`
(same-sitting provenance), `cross_links`, and shared carrier issue, and each
member records which substrate reached it.

**AC3 — the join does not hold by equality (§13.3).** Given a Grain whose
`source_batch` is a legacy numbered value, when the batch-mate lookup runs,
then it joins through the batch record's `members` rather than by equality.

**AC4 — unresolved is marked, never empty (§13.3).** Given a `source_batch`
that cannot be resolved, when the lookup completes, then an **explicit
unresolved marker naming the value** is emitted and an empty result is never
presented as "this Grain has no same-sitting siblings".

**AC5 — the bound is expressed in traversal terms (§13.3, v14).** Given a
Thesis, when the bound is applied, then it is expressed as **substrates ×
depth** (which provenance links are followed, and how far) and never in terms
of the neighbors yielded; and no enumerated neighbor is scored, ranked, or
dropped on relevance at any point.

**AC6 — empty is a result about the corpus (§13.2, §13.3 v14).** Given a Thesis
whose declared substrates yield no members, when the traversal completes, then
the outcome is reported as an informative empty — the traversal ran and found
nothing — and never as a failure or as a bound that halted before looking.

**AC7 — the Thesis→substrate mapping is read, not derived (§13.3, §13.5
v14).** Given the subcommand runs, when it resolves which substrates to
traverse for a Thesis, then it reads a **declared** mapping; and when no
declaration covers the Thesis, then it refuses or reports rather than inferring
one. A mapping computed from the Thesis at call time is §13.5's extension
entered without its trigger.
