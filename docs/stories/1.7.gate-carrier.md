sequencing decision (2026-08-05) ordered this subsystem ahead of Terrain

As the Kogaki repository owner, I want gates to have a declared carrier, so
that gate rendering is contract rather than discretion — the property that
failed fourteen times in the predecessor before attribution was made
structural.

## Context

`specs/SPEC.md:99-101` carries this subsystem's contract inline, as the
manifest's admission record:

> "4. **The gate carrier** (declared gate registry, AskUserQuestion evidence,
> payload/answer capture) — with rendering through the question UI as
> contract, not discretion."

The medium binding is served and quoted verbatim at its pin:

> "'In a Claude Code host, a gate renders through the selector affordance,
> never prose' is RATIFIED as the rule's first named MEDIUM BINDING, and it
> is what makes the rule checkable. The general form — visually distinct from
> the surrounding report — is unfalsifiable on its own, since every author
> believes their own gate is distinct; all seven observed failures were
> authored by someone who thought the gate was legible."

## Acceptance criteria

- **Given** a gate this repository raises, **when** it is declared, **then**
  it appears in a **gate registry** — the enumeration against which coverage
  is measured. An unregistered gate is the uncovered-by-default shape, so
  the registry is what makes a coverage claim mean anything.
  (New behavior; the contract is `specs/SPEC.md:99-101`.)
- **Given** a gate runs in a Claude Code host, **when** it reaches the owner,
  **then** it renders through the **selector affordance** and never as prose.
  This is the checkable form of the legibility rule, per the served line
  above.
- **Given** a gate is answered, **when** the answer is recorded, **then**
  both the **payload** (what was offered) and the **answer** are captured.
- **Given** the capture path cannot produce a row, **when** the carrier
  reports, **then** it reports a **crash as a crash** and never as its
  positive finding. A checker whose fallback message is phrased as its
  finding converts every internal error into a false accusation, and
  identical repeated output must disclose its repetition rather than read as
  accumulating evidence
  (`consulted: product-lab@924cce3b5fd2b3b17f906caa2b0c2f6a332003a6 topics/claude-code-ops.md:14`).
- **Given** any guard on the capture path, **when** it is tested, **then**
  each write path has its own fixture — including the gate-less row, which
  the served instance above records as the case no fixture held.
- Registered in `checks/registry.json` with a complete admission record —
  contract carried, license `kogaki#14` plus this story's own issue, tier,
  measured runtime, and a removal signal declared at birth
  (`checks/registry.json:2-7`).

## Story questions

- The gate registry's file location and shape are the implementer's call;
  the criteria bind the enumeration and its coverage claim, not the format.
- Whether Kogaki's registry can be the same artifact as
  `checks/registry.json` is undecided. That registry's own note scopes it to
  the **mechanical** suite (`checks/registry.json:2-7`), and a gate is a
  judgment surface — cannot-determine, so it is not written as a criterion.
