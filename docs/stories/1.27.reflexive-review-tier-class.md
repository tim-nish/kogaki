Umbrella: https://github.com/tim-nish/kogaki/issues/99. On conflict, the
umbrella issue and `specs/SPEC.md` §4 ("Review altitude is a declared property
of the diff") win.

As the owner of the review pipeline, I want a change to the review machinery to
be reviewed at the careful tier, so that the classifier stops calling its own
instrument cheap and a PR touching the reviewer stops stalling at the ordinary
cap without producing a report.

## Context

The tier table shipped by story 1.19 classes by path
(`tools/review-sweep.sh:549-554`), resolved by `resolve_tier()` at
`tools/review-sweep.sh:804`. `tools/**` and `.claude/skills/**` are both on the
ordinary side, so `tools/review-sweep.sh` itself and
`.claude/skills/review-lane/SKILL.md` review at `sonnet`/24. Measured on
PR #98: two consecutive spawned reviewers, both `error_max_turns` at 25 turns
against a cap of 24, ~$2 spent, no report posted.

`specs/SPEC.md` §4's review-altitude bullet (added under kogaki#99
alternative A) is this story's governing text. It writes the previously
implicit tier invariant down and declares a **third class above both existing
ones**.

## Acceptance criteria

1. **Given** a diff any of whose paths touches the reviewing instrument,
   **when** the tier is resolved, **then** the reflexive class is matched
   **before** the careful/ordinary axis and the review runs at the careful
   tier's model and cap. Today `resolve_tier()` at `tools/review-sweep.sh:804`
   tests careful first (`careful_hit` at `:828`) and this criterion inserts a
   prior test, so precedence is a code fact rather than an ordering accident.

2. **Given** the reflexive class, **when** it is declared, **then** its
   membership sits beside `TIER_CAREFUL_PATHS` and `TIER_ORDINARY_PATHS`
   (`tools/review-sweep.sh:549-554`) and carries an operator override of the
   same shape they carry — the file's own stated rule, "one place to read, one
   place to change" (`tools/review-sweep.sh:538`).

3. **Given** the existing careful/ordinary table, **when** this ships,
   **then** it is **unchanged**: no path moves between `TIER_CAREFUL_PATHS` and
   `TIER_ORDINARY_PATHS`. The whole widening is the new class.

4. **Given** a resolved tier, **when** the run reports it, **then** the run's
   line names the reflexive class by name when it fired. `resolve_tier()`
   already returns a `class` and a `why`, and `review_policy()` at
   `tools/review-sweep.sh:843` already renders "class {klass} ({why})"; the
   new class uses that existing path and adds no second reporting surface.
   This matters for the same reason the fallback must say so: an unobservable
   classification is the defect kogaki#65 was filed over
   (`tools/review-sweep.sh:807-810`).

5. **Given** the non-member fallback, **when** a path matches no declared
   class, **then** it still falls to the careful tier. This story adds a class
   above the axis and does not touch the fail-safe.

6. **Given** the resolver's fixture, **when** this ships, **then** it covers a
   reflexive-only diff, a mixed reflexive-plus-ordinary diff (reflexive wins),
   a mixed reflexive-plus-careful diff (careful tier either way, but the class
   reported is the reflexive one), and an unchanged ordinary diff. The fixture
   is the existing one driven through `resolve_tier(..., **tables)` at
   `tools/review-sweep.sh:1686`.

## Blast radius

- `tools/review-sweep.sh` — the tier table block and `resolve_tier()`, plus the
  existing resolver fixture. **Accepted overlap with story 1.28**, which edits
  the spawn wrapper and `COMPOSITION` prompt in the same file; 1.28 declares
  `depends_on: 1.27` so the two land in sequence.
- `specs/SPEC.md` — already amended by the sitting that created this story.
- `checks/**` — **unchanged**.

## Story questions

- *What exactly is "the reviewing instrument"?* `tools/review-sweep.sh` and
  `.claude/skills/review-lane/**` are the two the measured defect names. Whether
  `checks/check-review-report.sh` belongs — it is already `careful` via
  `checks/**`, so membership would change nothing today but would change the
  reported class — is not decided here.
- *Does the reflexive class want a cap ABOVE the careful tier's 60?* The
  measured stall was against 24. Whether 60 suffices for a review that runs the
  machinery's own fixture pass is **unverified — not measured this sitting**,
  and is a question rather than a criterion. The register note
  (class `cap-vs-required-opening-move`) is the adjacent evidence — written
  when the register was still kogaki#13, and now carried at kogaki#246, the
  lane's own register carrier since the kogaki#191 split.
